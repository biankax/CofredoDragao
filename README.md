# 🐉 Cofre do Dragão

> Sistema web de controle financeiro pessoal.

O **Cofre do Dragão** é uma aplicação Full Stack desenvolvida para auxiliar no controle das finanças pessoais, permitindo organizar despesas, acompanhar gastos e visualizar informações financeiras de forma simples e intuitiva.

## 🚧 Status do projeto

**Em desenvolvimento**

## 🛠️ Tecnologias

### Frontend

- React
- TypeScript
- Vite
- Styled Components

### Backend

- NestJS
- Node.js
- TypeScript

## 📖 Sobre

O **Cofre do Dragão** é uma aplicação desenvolvida para auxiliar no controle e organização das finanças pessoais.

O projeto combina funcionalidades de controle financeiro com uma identidade visual inspirada em jogos pixel art, utilizando um dragão como mascote.

---

## ✨ Funcionalidades

- 💰 Controle de saldo
- 📈 Registro de entradas
- 📉 Registro de saídas
- 🗂️ Organização de gastos por categoria
- 💳 Gerenciamento de cartões
- 📊 Relatórios financeiros
- 👤 Gerenciamento de usuários

> Algumas funcionalidades ainda estão em desenvolvimento.

## 🎨 Interface

A aplicação utiliza uma identidade visual baseada em **pixel art**, com:

- 🐉 Dragão como mascote
- 🪙 Elementos inspirados em moedas e tesouros
- 🔷 Paleta de tons azuis
- 🎮 Ícones pixelados
- 🧩 Interface simples e intuitiva
